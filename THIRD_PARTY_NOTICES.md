# Sources and notices

Doozo adapts workflow ideas and selected instructions from these projects. It does not require those plugins to be installed.

| Source | Contribution | Notice |
|---|---|---|
| Pstack / Poteto Mode, Lauren Tan | Scoped delegation, verification, review and writing guidance | [MIT](licenses/pstack-MIT.txt) |
| Ponytail, DietrichGebert | Existing code, standard library and native features before additional implementation | [MIT](licenses/ponytail-MIT.txt) |
| mattpocock/skills, Matt Pocock | Dependency-aware design interviews, domain vocabulary, concise decision records and skill authoring | [MIT](licenses/mattpocock-skills-MIT.txt) |
| thananon/9arm-skills, Debug Mantra | Reproduction, failure tracing, hypothesis disproof and experiment history | Independently written Doozo instructions. No upstream text is bundled because no license notice was established. |
| User-supplied Parallel Agent Orchestrator | Scout, implementation, fresh review and parent integration | Independently written role workflow |
| agent-browser | External browser command interface | Separate optional installation; no implementation or complete guide bundled |

Sources were inspected on 2026-09-05. The Ponytail distribution was version 4.9.0. The local planning inventory records the source file hashes; runtime behavior is verified separately.
